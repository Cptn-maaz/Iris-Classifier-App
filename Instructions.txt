Step 01: 
Run the notebook on colab (you can also run it on kaggle or anaconda) to develop the model.
In the notebook all the process of model development are given step by step i.e (Loading Dataset, Preprocessing, Model Training, Model evaluation, downloading the model).

Step 02: 
Select a folder or make a new folder i.e (Project) in your pc for your project and paste all the files i.e (downloaded model, streamlit_app, pictures) in that folder.

Step 03: 
i)   Open anaconda prompt in pc
ii)  Move the control to that Project (folder) and create a virtual environment using the following code.
     'conda create -n iris_env python=3.10'
     This will create a virtual environment named as "iris_env in your directory.
iii) Activate the created virtual environment using the following code
     'conda activate iris_env'
     This will active your created environment, now the control will be in this environment like
     (iris_env) C:\Users\YourName>
You can also watch the following video on how to setup a virtual environment for a project
https://www.youtube.com/watch?v=5MDv8R5UGqQ&list=PLxf3-FrL8GzTIQpnY_UyzDX6JK0_Kbe_t&index=32&ab_channel=IrfanMalik


Step 04:
Install the requied packages by running the following command
pip install streamlit scikit-learn numpy joblib

Now open the vs code editor, select the created virtual environment and open the "streamli_app" file.
